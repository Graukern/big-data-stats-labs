# Лабораторные работы по курсу «Статистика больших данных» СПбПУ (осень 2026 г.)

## Требования

Python 3.10+

## Структура

Каждая лаба лежит в своей папке в формате `labXX/src/main.py`, например:

```
lab01/
    src/
        main.py
```

## Лабораторные работы

- **lab01/** — операции над векторами (генерация, чередование, сортировка), вычисление норм вектора (L1, L2, L∞, взвешенная), факториал числа, ввод данных с клавиатуры
- **lab02/** — проверка статистических гипотез, принцип Бонферрони, оценка вероятности случайных совпадений в последовательностях, эффект множественных сравнений на примере критерия Стьюдента и A/B-тестирования
## Как запустить

Клонировать репозиторий и перейти в нужную папку с лабой, например:

```bash
git clone https://github.com/Graukern/big-data-stats-labs.git
cd big-data-stats-labs
python lab01/src/main.py
```

Внешние библиотеки не используются — venv нужен только для изоляции окружения, для запуска самого кода он не обязателен.
