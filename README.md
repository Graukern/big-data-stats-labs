## Структура

Код каждой лабы лежит в `labXX/src/main.py`. Если по лабе есть отчет в LaTeX, он лежит рядом с кодом (в `lab02` отчет без кода):

```
lab01/
    src/
        main.py
lab02/
    report.tex

lab06/
    report/
        report.tex
        report.pdf
    src/
        main.py
```

## Лабораторные работы

- **lab01/** — операции над векторами (генерация, чередование, сортировка), вычисление норм вектора (L1, L2, L∞, взвешенная), факториал числа, ввод вектора и весов с клавиатуры (лекция 4)
- **lab02/** — проверка статистических гипотез, принцип Бонферрони, оценка вероятности случайных совпадений в последовательностях, эффект множественных сравнений на примере критерия Стьюдента и A/B-тестирования (лекция 8); отчет в LaTeX
- **lab03_1/** — выделение тренда простым скользящим средним и скользящей медианой (окна 21, 51, 111), сравнение с точным трендом, проверка остатков на случайность по числу поворотных точек и коэффициенту Кендэла (лекция 9)
- **lab03_2/** — экспоненциальное скользящее среднее (α = 0.01, 0.05, 0.1, 0.3), амплитудный спектр Фурье и главная частота, проверка остатков на случайность, несмещенность и нормальность (лекция 10)
- **lab04_1/** — разложение ряда методом Прони, анализ среднесуточных температур за два года на тренд и сезонные колебания, показатель Херста (лекция 11); данные Open-Meteo кэшируются в `lab04_1/data/`
- **lab04_2/** — обнаружение аномальных значений правилом трех сигм и боксплотом Тьюки, сравнение методов (лекция 12)
- **lab05/** — робастные оценки параметра положения: выборочное среднее, медиана, оценка Хубера и двухэтапная оценка, сравнение по методу Монте-Карло для N(0,1), C(0,1) и их смеси (лекция 16); отчет в LaTeX
- **lab06/** — простая линейная регрессия зависимости веса от роста (ручной расчет, RSS, RSE, R²), мультипликативная модель зависимости веса от возраста (лекция 18); отчет в LaTeX
- **lab07/** — множественная линейная регрессия (RSS, RSE, R², F-критерий), полиномиальная регрессия среднегодовой температуры Тюмени за 1986–2025 гг. и выбор степени полинома прямым отбором (лекции 19–20); данные pogodaiklimat.ru в `lab07/data/`

## Как запустить

Клонировать репозиторий и перейти в нужную папку с лабой, например:

```bash
git clone https://github.com/Graukern/big-data-stats-labs.git
cd big-data-stats-labs
python lab01/src/main.py
```

Для lab03–lab07 нужны `numpy` и `matplotlib`, для lab07 еще `scipy` (удобно поставить в venv). Все графики лабы открываются одновременно, вывод чисел — в консоль.
